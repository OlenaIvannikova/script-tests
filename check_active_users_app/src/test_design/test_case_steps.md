# Шаги тест кейса

1) Set up the test data (подготовка данных в виде CSV, TXT, JSON файлов)
### создание users.txt
- генерация данных для users.txt с параметром - количество строк (num)
- установка конкретных логинов пользователей (user1, user2)

### создание logins.csv
- генерация данных с параметром - количество строк (num)
- установка конкретных данных (login, last_login) и при этом login есть в users.txt
- установка конкретных данных (login, last_login) и при этом login отсутствует в users.txt
- генерация данных с невалидным разделителем CSV файла

### создание banned.json
- генерация валидного json: установка конкретных логинов
- генерация невалидного json

2) Execute the script (запуск скрипта)
- успешный запуск скрипта с 3 входными файлами (exit code 0)
- установка параметров запуска (usersFilePath, loginsFilePath, bannedFilePath) 
- установка параметров запуска (запуск без параметров)
- установка параметров запуска (запуск с 2мя параметрами)
- неуспешный запуск скрипта (exit code 1)

3) Verify the expected results (проверка результата в файле active_users.csv)
- проверка, что скрипт завершается успешно с exit code == 0
- проверка, что скрипт завершается неуспешно с exit code == 1
- проверка содержимого файла active_users.csv (построчно)
- проверка, что файл содержит только заголовок
- проверка правильного заголовка в файле active_users.csv
- проверка сообщения ошибки
