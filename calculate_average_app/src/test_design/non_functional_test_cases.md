# Non-functional test cases

# Suite 1: Performance tests
## Test Case 1 "Обработка 10 000 транзакций"
Тест проверяет: скрипт выполняется не больше 1 секунды

given
- генерация данных с параметром - количество строк (10 000 транзакций)

when
- успешный запуск скрипта (exit code 0)
- измерение времени выполнения процесса

then
- exit code == 0
- время выполнения <= 1 секунды

given
- генерация данных с параметром - количество строк (100 000 транзакций)

when
- запуск cкрипта указанное количество раз (5 раз)
- измерение времени выполнения каждого запуска

then
- каждый из 5 запусков завершается с exit code == 0
- каждый запуск выполняется <= 5 секунд
