# Шаги тест кейса

1) Set up the test data (подготовка данных в виде CSV)
- генерация данных с параметром - количество строк
- установка конкретных данных (user, date, category, amount)
- генерация данных с невалидным разделителем CSV файла

2) Execute the script (запуск скрипта)
- успешный запуск скрипта (exit code 0)
- неуспешный запуск скрипта (exit code 1)
- установка параметра запуска ( параметр - путь к файлу с транзакциями: filePath) (пустой путь, несуществующий путь)
- запуск cкрипта указанное количество раз (параметр numberOfRuns)

3) Verify the expected results (gроверка результата в файле averages.csv)
- проверка содержимого файла averages.csv (построчно)
- проверка сообщений ошибок
- проверка правильного заголовка в файле averages.csv
- проверка, что каждый из нескольких запусков завершается с exit code == 0
- проверка, что каждый запуск из нескольких запусков выполняется <= 5 секунд
